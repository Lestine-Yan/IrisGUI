# IrisGUI
**IrisGUI**是一个使用 **C++** 编写的开源图形用户界面组件库，构建在 **EasyX 图形库** 之上。项目旨在为 EasyX 提供一套更丰富、易用且风格现代的组件，弥补 EasyX 原生仅提供基本绘图功能的不足，使开发者能够快速搭建具备完整交互界面的 Windows 桌面程序，而无需依赖 MFC 或 Qt 等重型框架。
# 项目目标
- **降低 EasyX 界面开发门槛**：提供开箱即用的 UI 组件，开发者只需几行代码即可创建带按钮、输入框、列表等的界面。
- **组件扩展与封装**：对常见 GUI 元素（按钮、文本框、滑块、下拉菜单等）进行封装，抽象出统一的基类，支持事件响应、样式定制、布局管理。
- **易集成、轻依赖**：仅需 EasyX 库（Windows 下 VC++ 环境），无需第三方框架，适合教学、竞赛、小型工具开发。
- **性能与可定制性**：组件基于 EasyX 的绘图命令实现，绘制高效；同时通过虚函数和回调机制，允许用户自定义外观（颜色、圆角、字体等）与行为。
